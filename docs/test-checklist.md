# 動作確認チェックリスト

デプロイ後に一通り確認するためのチェックリスト。上から順に試すと依存関係（仮予約→承認→確定→キャンセル）が繋がる。

## 0. 前提確認
- [ ] `clasp deployments` で本番デプロイのバージョンが最新になっている
- [ ] スクリプトプロパティに `CALENDAR_ID` / `DISCORD_WEBHOOK_URL` / `LINE_CHANNEL_ACCESS_TOKEN` / `SPREADSHEET_ID` / `ADMIN_EMAILS` が設定されている

## 1. 新規予約（ゲスト側）
- [ ] LIFF（LINEアプリ内）から予約フォームを開き、ログイン状態になる（未ログインならログイン画面に飛ぶ）
- [ ] カレンダーで当月の空き日（○）が選べる。翌月ボタンで表示月が切り替わり、範囲外では次へボタンが無効になる
- [ ] 人数・時間・スペース・飲み放題・ご利用履歴を選択し、氏名（漢字でもカタカナでも可）・電話番号を入力して送信できる
- [ ] 送信後、完了画面が表示される
- [ ] スプレッドシートに新しい行が「仮予約」として追加されている（電話番号の先頭0が消えていないか確認）
- [ ] Discordに新規予約の通知が届く（承認画面へのリンク付き）

## 2. 承認（Discordの承認リンクから）
- [ ] 承認リンクを開くと、予約内容がフォームに入っている
- [ ] 「承認して確定」を押すと、確定完了画面に切り替わる
- [ ] スプレッドシートのステータスが「確定」になる
- [ ] Googleカレンダーに予定が登録される（日時・人数・スペースが合っているか）
- [ ] スプレッドシートの「カレンダーイベントID」列に値が入る
- [ ] LINEに確定通知が届く（日時が「10月1日(木) 16:00」のような表記になっているか）
- [ ] Discordに確定報告が届く

## 3. 管理者画面
- [ ] `frontend/admin.html`（または直接デプロイURL+`?page=admin`）を開くと管理者画面が表示される（`ADMIN_EMAILS`未登録のアカウントでは「アクセス権がありません」になる）
- [ ] 予約一覧・統計タイル（本日の予約／未対応の仮予約／今月の確定／本日の合計人数）が表示される
- [ ] ステータスタブ（すべて／仮予約／確定／キャンセル）で絞り込める
- [ ] 氏名・電話番号での検索が効く
- [ ] 行をクリックすると詳細パネルが開く

### 3-1. 仮予約の却下
- [ ] 仮予約の詳細パネルで「却下」を押すとステータスが「キャンセル」になる
- [ ] LINEに却下の連絡が届く（LINE UserIdがある場合）
- [ ] Discordに却下の連絡が届く

### 3-2. 確定済み予約のキャンセル
- [ ] 確定済みの詳細パネルで「キャンセルにする」を押すとステータスが「キャンセル」になる
- [ ] **Googleカレンダーから該当の予定が削除される**
- [ ] LINEにキャンセルの連絡が届く
- [ ] Discordにキャンセルの連絡が届く

## 4. 前日リマインド
- [ ] GASエディタで`sendReminders`を手動実行し、翌日が確定日の予約に対して以下が送られる
  - [ ] LINE通知（LINE UserIdがある場合）
  - [ ] メール（メールアドレスが登録されている場合）
  - [ ] Discord通知

## 5. 定員（空き状況）
- [ ] 同じ日に複数組の確定予約があっても、合計人数が15人未満なら空き（○）表示のまま
- [ ] 合計人数が15人に達すると、その日は満席（－）表示になる

## 6. セキュリティ
- [ ] 氏名欄に `<img src=x onerror=alert('test')>` のような値を仕込んだ予約を送っても、管理者画面でスクリプトが実行されず、文字列としてそのまま表示される
- [ ] 日時・氏名・電話番号のいずれかを欠いたリクエストを直接送ると、エラーが返り仮予約が作成されない

## 7. 通知先が空のケース
- [ ] LINE未ログイン（LINE UserIdなし）の予約を承認・キャンセルしても、GASの実行ログに警告が出るだけでエラーにならず処理は完了する
- [ ] メールアドレス未登録の予約は、リマインド時にメール送信をスキップする
